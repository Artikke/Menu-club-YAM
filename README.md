# Menu Club YAM

Sistema de pedidos de comida para los empleados de la oficina PROESA en Hermosillo.

## Como funciona

1. El empleado entra desde su celular a la pagina
2. Busca su numero de empleado
3. Elige los dias que va a comer
4. Guarda su pedido

La administradora configura el menu semanal, revisa los pedidos y comparte
el resumen a la cocinera por WhatsApp.

## Tecnologia

- Frontend: HTML + CSS + JavaScript (archivo unico)
- Datos: Firestore (proyecto menu-proesa-yama)
- Deploy: GitHub Pages

## Acceso

- Empleados: https://artikke.github.io/Menu-club-YAM/
- Administracion: misma URL, seccion de admin con PIN
