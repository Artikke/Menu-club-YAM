## Que datos tiene esta app

| Dato | Descripcion | Volumen estimado |
|---|---|---|
| Catalogo de empleados | Numero, nombre y RFC de cada empleado | ~120 registros |
| Pedidos activos | Dias elegidos por cada empleado para la semana | ~50-80 por semana |
| Menu semanal | Platillos disponibles por dia | 5 dias |
| Cortesias | Invitados no empleados que comen esa semana | Variable, pocos |
| Historial | Archivo de pedidos por quincena | Crece cada 15 dias |
| Comentarios | Retroalimentacion de empleados sobre la comida | Variable |

## Endpoints de integracion

Esta app no ofrece endpoints de integracion. No tiene API propia.
Los datos se acceden directamente desde Firestore (proyecto menu-proesa-yama).

Para solicitar datos de esta app, abrir un issue cross-repo al especialista.

## Dependencias

Esta app no consume datos de otras apps del ecosistema PROESA.
